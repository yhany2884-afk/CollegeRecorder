## التشغيل

- أندرويد: ثبّت `mohadarat.apk` واسمح بالميكروفون.
- ويندوز: فك `Mohadarat-Windows-x64.zip` وشغّل `Mohadarat.exe`.
- ماك: فك الملف المناسب لجهازك، ثم زر يمين على `Mohadarat.app` واختار فتح.
- ويب: افتح شارة الويب.
- آيفون: افتح شارة آيفون في Safari، ثم مشاركة، ثم إضافة إلى الشاشة الرئيسية. مفيش ملف IPA لأن توقيع آيفون محتاج حساب مطوّر Apple.

التحويل لنص يحتاج نت. النسخ غير موقّعة من Apple وMicrosoft.

## المشروع

افتح المجلد في Android Studio مع JDK 17، استنى Gradle Sync، ثم Run.
