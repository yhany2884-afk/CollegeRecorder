# محاضراتي | College Recorder

تطبيق أندرويد احترافي لتسجيل المحاضرات وتحويلها لنص **أوفلاين**، مصمم خصيصاً لطلاب الكلية.

## المميزات الكاملة

### التسجيل
- تسجيل صوت عالي الجودة (AAC 128kbps / 44.1kHz)
- يعمل في **الخلفية** مع إشعار مستمر + أزرار تحكم
- إيقاف مؤقت / استئناف
- حماية من قتل التطبيق (WakeLock + طلب استثناء البطارية)
- تنظيم حسب المواد

### التحويل لنص (Speech-to-Text) — أوفلاين
- **Vosk** محرك قوي يعمل بدون إنترنت
- دعم العربية (موديل MGB2 ~318MB)
- دعم الإنجليزية (موديل صغير ~40MB)
- طوابع زمنية لكل جملة
- تحميل الموديل مرة واحدة فقط

### التلخيص والنقاط المهمة
- تلخيص تلقائي بعد التحويل
- استخراج النقاط المهمة من المحاضرة

### التنظيم والمشاركة
- قاعدة بيانات محلية (Room)
- بحث داخل المحاضرات
- تصدير TXT / Markdown
- مشاركة سريعة

### الواجهة
- Material 3 حديث
- دعم الوضع الليلي
- واجهة عربية كاملة (RTL)

---

## طريقة التشغيل

### المتطلبات
- Android Studio Ladybug (2024.2+) أو أحدث
- JDK 17
- جهاز أندرويد أو Emulator (API 26+)

### الخطوات

1. Clone المشروع أو حمله كـ ZIP
2. افتح المجلد في **Android Studio**
3. استنى Gradle Sync يخلص
4. وصّل موبايلك أو شغّل Emulator
5. اضغط ▶ Run

### أول استخدام
1. التطبيق هيطلب صلاحية الميكروفون + الإشعارات
2. هيطلب استثناء من تحسين البطارية (مهم جداً)
3. سجّل محاضرة
4. افتح المحاضرة → حمل الموديل (عربي أو إنجليزي)
5. اضغط **تحويل المحاضرة لنص**
